@dotgui/embed

One element: <gui-embed>. Inline content via a <script type="application/gui"> child, or src for a file. No chrome by default; add booleans for the widget.

1 · Standalone preview — inline content, no chrome

Sizes to the file's native size. Parser-safe (the <col> survives).

2 · Standalone preview — external file via src

Fetched, unzipped, rendered. Width fixed; height follows the file's ratio.

3 · Widget — fixed canvas + controls + dot grid

zoom download copy grid — hover to reveal the bar. Center-center, scaled to fit.
